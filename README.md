# LangMeet — Платформа онлайн-встреч для изучения иностранных языков

**ИС «LangMeet»** — информационная система языкового обмена, которая обеспечивает регулярную разговорную практику на иностранном языке. Система подбирает собеседников по языку, уровню, интересам и времени, проводит аудио- и видеосессии через WebRTC, сопровождает их методическим «Путеводителем тем» и дидактическими играми.

Проект выполнен в рамках лабораторных работ по дисциплине «Проектирование и разработка ПО» (БГУ, факультет радиофизики и компьютерных технологий, кафедра интеллектуальных систем).

## Краткое описание

- **Рынок:** EdTech, онлайн-изучение языков (СНГ, фокус — русскоязычная аудитория).
- **Сегменты:** C2C (самостоятельно изучающие язык), B2C (репетиторы), B2B (языковые школы и корпоративные клиенты).
- **Монетизация:** Freemium, подписка от 5 USD/мес, комиссия 15% с репетиторов, B2B-подписка.
- **Срок реализации:** 6 месяцев. Инвестиции: 444 929,25 BYN (включая оборотный капитал).
- **Целевые показатели:** 5 000 MAU к концу первого полугодия функционирования; NPV = +97 546 BYN; IRR ≈ 20,3%.

|---|---|
| Серверная часть | Node.js, Python (микросервисы), REST API, WebSocket |

## Сборка и запуск (предполагаемые шаги)

> Код находится на стадии проектирования. Ниже описан целевой порядок запуска, который будет реализован в следующих итерациях разработки.

1. Клонировать репозиторий: `git clone https://github.com/<логин>/langmeet.git`.
2. Скопировать `config/.env.example` в `config/.env` и заполнить переменные (строки подключения к PostgreSQL и Redis, секрет JWT, ключ платёжного шлюза).
3. Запустить инфраструктуру: `docker compose -f config/docker-compose.yml up -d`.
4. Запустить сервисы из папки `src/` (после реализации): `npm install` и `npm start` для Node.js-сервисов, `pip install -r requirements.txt` и `python main.py` для Python-сервисов.
5. Открыть web-клиент: `http://localhost:3000`. API доступен по адресу `http://localhost:8080/api/v1`.

## Для разработчиков

1. Создайте ветку от `main`: `git checkout -b feature/<краткое-описание>`.
2. Внесите изменения и закоммитьте их.
3. Отправьте ветку: `git push -u origin feature/<краткое-описание>`.
4. Откройте Pull Request в `main` и дождитесь ревью.
5. Не коммитьте в `main` напрямую.

**Соглашения:**
- Эндпоинты API имеют префикс `/api/v1`, ответ — JSON с полями `data` / `error`.
- Первичные ключи — `uuid`. Межсервисные ссылки хранятся как `uuid` без внешних ключей.
- Пароли хранятся только как хэш Argon2id.
- Формат сообщений коммитов: `тип: краткое описание` (`docs:`, `feat:`, `fix:`, `perf:`, `chore:`).
