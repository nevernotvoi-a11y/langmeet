# Журнал изменений Технического задания

Версия 1 → версия 2. Основание: фидбек итерации 2 (docs/feedback/iteration_2_feedback.md).

## Изменения в тексте ТЗ

### Раздел 4.2. Требования к функциям (задачам)

Добавить в подраздел «Управление пользователями и профилями»:
> Двухфакторная аутентификация (TOTP) обязательна для ролей «преподаватель» и «администратор».

Добавить в подраздел «Подбор собеседников» новый пункт:
> Приглашение собеседника по ссылке: создание приглашения с ограниченным сроком действия; принятие приглашения создаёт сессию без прохождения очереди подбора.

Добавить в подраздел «Отзывы и модерация» (или новый подраздел «Отчёты»):
> Экспорт отчёта по итогам сессии в формат PDF для преподавателя.

### Раздел 4.4.2. Требования к показателям назначения

Было: «отклик API ≤300 мс (95%)».
Стало: «отклик API ≤200 мс (95%) для запросов статуса заявки и данных сессии; ≤300 мс (95%) для остальных запросов».

### Раздел 4.4.4. Требования по безопасности

Добавить пункт:
> Обязательная двухфакторная аутентификация (TOTP) для ролей «преподаватель» и «администратор»; ограничение попыток ввода кода (5 попыток, затем блокировка на 15 минут).
