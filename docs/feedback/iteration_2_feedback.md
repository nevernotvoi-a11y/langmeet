# Фидбек заказчика по итогам тестирования — итерация 2

Дата: 2026. Источник: имитация обратной связи преподавателя по результатам ревью ЛР №1–4.

| № | Замечание / новое требование | Категория | Какие документы меняются |
|---|---|---|---|
| F1 | Добавить двухфакторную аутентификацию (TOTP) для ролей «Преподаватель» и «Администратор» | Безопасность | Use Case (прецедент «Пройти 2FA»); Sequence «Авторизация»; API (`POST /api/v1/auth/2fa/verify`, код `INVALID_MFA_CODE`); ТЗ п. 4.4.4 |
| F2 | Ускорить отклик API: p95 ≤ 200 мс для запросов статуса заявки и сессии (вместо ≤ 300 мс) | Производительность | ТЗ п. 4.4.2; архитектура (кэш статусов в Redis, read-реплика PostgreSQL); API (заголовок `Cache-Control`) |

| F4 | Экспорт отчёта по итогам сессии в PDF для преподавателя | Функциональность | Use Case (прецедент, расширение «Провести сессию»); API (`GET /api/v1/sessions/{session_id}/report?format=pdf`); ТЗ п. 4.2 |

Приоритет: F1 — высокий (безопасность ролей с доступом к данным), F2 — высокий (SLA), F3 и F4 — средний.
